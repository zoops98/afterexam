작년과 올해 시험지, 시험 범위 원문을 함께 살펴봅니다.
문항별 변형·난이도·변별력을 분석하고 다음 시험의 준비 방향을 정리하세요.

01 · CONNECTION

분석 모델 연결

키는 이 브라우저에 제공사별로 자동 저장·복원됩니다. 작업 파일과 보고서에는 포함하지 않습니다.

연결 전

저장된 키 확인 중

암호화된 보관함은 아닙니다. 공용 PC에서는 사용 후 각 제공사의 ‘키 지우기’를 눌러주세요.
모델: gpt-6-sol · Responses API

분석을 실행하면 선택한 AI 제공사에 업로드 자료가 전송되며 API 사용료가 발생합니다. 파일은 문항 묶음마다 다시 전송될 수 있습니다. 이 HTML은 개인 PC에서 사용하는 도구입니다.

02 · EXAM PROFILE

시험 기본 정보

시험지 표지에서 확인한 정보가 입력값과 다르면 확인 단계에서 알려드립니다.

03 · SOURCE MATERIALS

자료 업로드

PDF · JPG · PNG · WEBP · UTF-8 TXT/MD / 여러 파일 선택 또는 끌어놓기

0개 자료
PDF는 파일별 전체 페이지 수를 입력해주세요. 원본 표기와 대조하기 위한 필수 기준입니다. 한 파일은 12MB·20페이지 이하, 각 연도의 시험지·원문·정답표 합계는 30MB 이하로 준비해주세요. 긴 자료는 PDF를 나누어 올릴 수 있습니다.
작년 원문 · 공식 정답표 추가

작년 원문이 없으면 작년 시험의 출처·변형 비교는 미확인으로 표시합니다. 정답표는 선택 자료입니다.

한글(HWP/HWPX)·워드(DOCX)는 PDF로 저장한 뒤 올려주세요. 스캔본은 잘림 없이 선명하게 준비하세요. 텍스트 파일은 한 자료 단위로 다루며 시각적 밑줄·도형 검증에는 PDF가 필요합니다.

올해 시험지와 올해 시험 범위 원문은 필수입니다.
V2 분석 원칙과 사용 순서
  1. 자료 등록: 시험지와 원문을 연도별로 올립니다.
  2. 문항 확인: 전체 페이지, 표지 정보, 선택형·서답형 번호와 수를 원본과 대조합니다.
  3. 정밀 분석: 문항을 4개씩 원문과 비교합니다. 중단 후에는 미처리 문항부터 이어집니다.
  4. 총평: 필수 항목과 문항 커버리지를 검증한 뒤 생성합니다. AI 결과 검토 후 HTML/PDF로 저장합니다.

자료에 없는 출처·정답·정답률을 만들지 않습니다. 출처 미확인은 별도 집계하며, 판독 불가나 누락이 있으면 최종 총평을 생성하지 않습니다. AI의 교육적 판단은 교사 검토가 필요합니다.

STEP 02

빠짐없이 읽었는지 확인하세요.

AI가 읽은 내용과 실제 시험지를 대조하는 단계입니다.

아직 문항 목록이 없습니다.자료 등록에서 파일을 올린 뒤 문항 목록을 만들어주세요.
STEP 03

원문에서 답을 찾는 분석.

필수 항목과 근거를 검사하고, 누락된 분석은 완료로 처리하지 않습니다.

분석 대기 중

문항 확인을 마치면 정밀 분석을 시작할 수 있습니다.

중단·오류가 나도 완료된 문항은 이 창에 남습니다. 창을 닫기 전 상단의 ‘작업 저장’을 눌러주세요. 네트워크 중단 후에도 제공사에서 이미 처리한 요청에는 비용이 발생할 수 있습니다.

진행 기록이 여기에 표시됩니다.
STEP 04

시험 총평 보고서

전 문항 분석과 연도별 비교를 하나의 보고서로 확인하세요.

미검토 상태에서도 저장할 수 있으며 보고서에 ‘AI 분석 · 교사 검토 전’이 표시됩니다.
문항별 분석이 먼저입니다.정밀 분석에서 검증을 통과한 뒤 총평을 생성해주세요.
